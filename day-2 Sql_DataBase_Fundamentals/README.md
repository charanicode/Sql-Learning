# 📅 Day 2: SQL Database Fundamentals

## 📌 Overview

Today, I learned important database concepts related to relational database management systems, data redundancy, normalization, keys, and constraints. These concepts help in designing structured databases and maintaining data accuracy and integrity.

## 📚 Topics Covered

### 1. RDBMS (Relational Database Management System)

- Learned how data is organized into tables consisting of rows and columns.
- Understood how relationships can be established between tables.
- Explored how relational databases store, retrieve, and manage structured data.

**Examples:** MySQL, PostgreSQL, Oracle Database, and Microsoft SQL Server.

### 2. Data Redundancy

- Learned about unnecessary duplication of data in a database.
- Understood how redundant data can increase storage requirements and cause data inconsistency.
- Explored why reducing unnecessary duplication is important for database design.

### 3. Data Normalization

- Learned how normalization organizes data into well-structured tables.
- Understood how normalization helps reduce data redundancy and improve data integrity.

### 4. Keys in SQL

Learned about different types of database keys and their roles in identifying records and establishing relationships between tables.

- **Primary Key:** Uniquely identifies each record in a table and cannot contain NULL values.
- **Foreign Key:** Establishes a relationship with a key in another table or the same table.
- **Composite Key:** A key consisting of two or more columns.

### 5. Constraints in SQL

Learned how constraints enforce rules on table data and help maintain data integrity.

- **PRIMARY KEY:** Uniquely identifies each record.
- **FOREIGN KEY:** Enforces referential integrity between related tables.
- **UNIQUE:** Prevents duplicate values in a column or combination of columns, subject to database-specific NULL behavior.
- **NOT NULL:** Prevents NULL values in a column.
- **DEFAULT:** Supplies a default value when one is not provided in an insert operation.

## 🎯 Learning Outcomes

- Understood the fundamentals of relational database management systems.
- Learned the importance of reducing data redundancy.
- Gained knowledge of database normalization.
- Understood how different keys identify records and establish relationships.
- Learned how SQL constraints maintain data accuracy and integrity.
