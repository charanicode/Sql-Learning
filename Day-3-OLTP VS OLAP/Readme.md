## 1️⃣ OLTP vs OLAP

Learned the differences between Online Transaction Processing (OLTP) and Online Analytical Processing (OLAP).

| Feature | OLTP | OLAP |
|---|---|---|
| Full Form | Online Transaction Processing | Online Analytical Processing |
| Purpose | Handles daily transactions | Supports data analysis |
| Operations | INSERT, UPDATE, DELETE | Complex analytical SELECT queries |
| Data | Current operational data | Historical and consolidated data |
| Queries | Usually simple and fast | Often complex |
| Example | Banking and order processing | Sales reports and business dashboards |

**Key Takeaway:** OLTP manages day-to-day business transactions, while OLAP helps analyze data and support business decisions.

## 2️⃣ Similarities Between Excel and SQL

Explored how Excel and SQL can perform similar data analysis tasks.

| Task | Microsoft Excel | SQL |
|---|---|---|
| Filter data | Filter feature | `WHERE` |
| Sort data | Sort feature | `ORDER BY` |
| Select columns | Select columns | `SELECT` |
| Calculate totals | `SUM()` | `SUM()` |
| Calculate averages | `AVERAGE()` | `AVG()` |
| Count records | `COUNT()` | `COUNT()` |
| Summarize data | PivotTables | `GROUP BY` with aggregate functions |

**Key Takeaway:** Both tools help organize, filter, and summarize data, but SQL retrieves and processes data stored in relational databases, while Excel works with spreadsheet data.
