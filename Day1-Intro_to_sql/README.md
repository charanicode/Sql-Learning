### 🛠️ Types of SQL Commands

- **DDL:** CREATE, ALTER, DROP, TRUNCATE
- **DML:** INSERT, UPDATE, DELETE
- **DQL:** SELECT
- **DCL:** GRANT, REVOKE
- **TCL:** COMMIT, ROLLBACK, SAVEPOINT

### 🎯 Learning Outcome
Developed a foundational understanding of SQL, its different variants, and the commands used to create, manage, and retrieve data from databases.
