## 📚 Topics Covered

### 1. SQL Set Operators

Learned and practiced different SQL Set Operators:

- `UNION` – Combines results from multiple SELECT queries and removes duplicate records.
- `UNION ALL` – Combines results from multiple SELECT queries while retaining duplicate records.
- `INTERSECT` – Returns only the common records present in both SELECT queries.
- `EXCEPT` – Returns records from the first SELECT query that are not present in the second SELECT query.

### 2. Basics of Subqueries

- Learned the fundamentals of writing a query inside another SQL query.
- Understood nested queries and how they work.
- Practiced using subqueries to retrieve data based on the results of another query.
- Explored the basics of using subqueries in filtering conditions.

### 3. UNION vs JOIN

Learned the differences between UNION and JOIN:

| **UNION** | **JOIN** |
|---|---|
| Combines rows from multiple result sets. | Combines columns from multiple tables. |
| Adds results vertically. | Combines results horizontally. |
| Requires compatible column counts and data types. | Uses related columns or join conditions. |
| Removes duplicates by default. | Does not automatically remove duplicate rows. |
