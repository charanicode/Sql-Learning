### 1. SQL Views

Views are virtual tables created using SQL queries. They help simplify complex queries and allow users to retrieve specific data without rewriting the original query.

| **Concept** | **Description** |
|-------------|-----------------|
| CREATE VIEW | Creates a virtual table based on a SELECT query. |
| SELECT FROM VIEW | Retrieves data from an existing view. |
| DROP VIEW | Deletes an existing view. |


### 2. Common Table Expressions (CTEs)

A Common Table Expression (CTE) is a temporary named result set that can be referenced within a single SQL statement. It helps break complex queries into smaller and more readable parts.

| **Concept** | **Description** |
|-------------|-----------------|
| WITH | Defines a Common Table Expression. |
| CTE Name | Assigns a name to the temporary result set. |
| SELECT | Retrieves data from the CTE. |
| JOIN | Combines CTE results with another table. |
